360T7 Evil Twin 固件（airgeddon + fluxion 工具链）

在 passwall-sing-box 基础上增加：
- 无线安全测试核心：aircrack-ng 全家、macchanger、nmap、tmux（airgeddon/fluxion 无头模式）、
  lighttpd+php8-cgi、GNU gawk/sed/grep、iptables-nft、tcpdump、net-tools
- PMKID：hcxdumptool + hcxtools
- WPS：reaver + pixiewps
- DHCP：kea-dhcp4（fluxion 硬依赖，连客户端追踪都解析 kea 租约格式）
- 自带源码包（custom-packages/，官方 feed 已淘汰）：mdk4（aircrack-ng/mdk4 e94422ce，
  去 pcre1 依赖——24.10 已淘汰 pcre1，且 pcre 仅影响可选的 ESSID 正则过滤）、
  cowpatty+genpmk（joswr1ght/cowpatty 0a274975，原作者仓库）、
  ettercap 0.8.4.1（Ettercap/ettercap v0.8.4.1 tag 0dc84097，手写 cmake 配方：
  PCRE2 可选直连、curses/GTK/plugins/geoip/lua 全关、BUNDLED_LIBS=OFF 强制系统库、
  补丁降 cmake 最低版本 3.25→3.16 适配 ubuntu-22.04 runner；装 ettercap/etterlog/
  etterfilter + libettercap.so + /etc/ettercap）
- 攻击工具整树内置（custom-packages/，钉官方 release tag，run 38742302041
  解包实测在位）：fluxion v6.32（FluxionNetwork tag 18d6c9e，装
  /usr/share/fluxion，/usr/bin/fluxion 链接；headless 自动回退 tmux 模式；
  补丁禁用启动联网查新——防无网超时、防 master.zip 覆盖钉版树）、
  airgeddon v12.02（tag 700ad7d，装 /usr/share/airgeddon，
  /usr/bin/airgeddon wrapper 强制 AIRGEDDON_WINDOWS_HANDLING=tmux +
  AIRGEDDON_AUTO_UPDATE=false 关启动更新检查）
- 整树打包坑：.pkgdir 建在 PKG_BUILD_DIR 内，install 段 cp -a 源树会
  "copy into itself"，须 tar 管道排除 .pkgdir/构建戳
- diy：service 垫片（procd 转发，fluxion 用）、rfkill/7zr/dsniff 三个 stub、
  airmon-ng 脚本直装（airgeddon 必需项；官方子包依赖已被 24.10 淘汰的
  wireless-tools，而脚本只是个 1600 行 bash，从 aircrack-ng 官方仓库按
  1.7 tag 取，与固件内 aircrack-ng 同版本，装 /usr/sbin/airmon-ng 同路径）
- nftables CLI（airgeddon 防火墙可选 nft 模式；默认走 iptables-nft 也已具备）
- ettercap 0.8.4.1 全家（ettercap/etterlog/etterfilter + libettercap.so +
  libettercap-ui.so + /etc/ettercap 配置）——已解开 run 38687501053 的
  sysupgrade 镜像实测在位（aarch64 ELF 与双库齐全），airgeddon et_sniffing 解锁

包名/可见性坑（实测 run 38585799298 manifest 得出）：
- php8-cgi 其实在 immortalwrt/packages@openwrt-24.10 一直有；缺席真因是它的
  DEPENDS 写 `php8`（不带 + 号 = depends），config 未显式开 CONFIG_PACKAGE_php8=y
  时 php8-cgi 符号不可见，被 defconfig 静默丢弃。已显式加 php8=y
- immortalwrt feed 无 `net-tools` 包名，route 命令由 net-tools-route 提供
  （PROVIDES:=route），config 已换用

已确认缺失（均有意不打包，对照 v6.32/v12.02 官方依赖清单+镜像实测）：
bully（reaver+pixiewps 顶替）、p7zip（stub）、crunch/hashcat/john/tshark
（离线破解/流量分析，路由器 CPU 无意义）、bettercap/beef/hostapd-wpe/asleap
（sslstrip2/BeEF/Enterprise 模式专用）
- bully：WPS 有 reaver+pixiewps 顶着，功能不受损
- p7zip：fluxion 的 7zr 仅"更新安装器"用（打包备份），攻击流程不碰，stub 顶上即可

fluxion 依赖检查说明：
mdk4/cowpatty 为真实包，rfkill/7zr/dsniff 由固件内 stub 满足（rfkill 返回 0——
mt76 本就无 rfkill 设备；7zr/dsniff 触发即报错——攻击流程从不调用）。
因此 fluxion 无需任何 sed 补丁即可通过依赖检查。

其余注意：
- 360T7 闪存为原厂 128MB NAND（硬改的是内存 512MB）。DTS 固定分区：ubi=108MB
  （0x580000 起 0x6c00000），当前 sysupgrade 51MB，剩余 ~50MB 自动成为
  rootfs_data 可写 overlay；再塞 fluxion/airgeddon（+3~5MB）无压力
- 假认证页依赖 80 端口：测试前停掉占用 80 的服务
